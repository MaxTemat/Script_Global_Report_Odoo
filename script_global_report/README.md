# Script Global Report

## Présentation

**Script Global Report** est un module Odoo 19 développé par **SCRIPT CONSULTING**.

Il ajoute une fenêtre de choix lors de l'impression d'un rapport Odoo afin de permettre à l'utilisateur de sélectionner l'action souhaitée.

Le module propose les options suivantes :

- **Imprimer**
- **Télécharger en PDF**
- **Ouvrir dans le navigateur**

L'objectif est de fournir une gestion centralisée et uniforme des options d'impression pour les rapports Odoo.

---

## Fonctionnalités

Lorsqu'un utilisateur lance l'impression d'un rapport, une fenêtre de sélection est proposée avec plusieurs possibilités :

### 🖨️ Imprimer

Permet de lancer directement l'impression du rapport.

### 📥 Télécharger en PDF

Permet de télécharger le rapport au format PDF.

### 🌐 Ouvrir dans le navigateur

Permet d'ouvrir le rapport dans le navigateur afin de le consulter avant impression ou téléchargement.
